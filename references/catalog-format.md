## Directory Structure

```
$SEEKB_PATH/                        # Default: ~/knowledge-base/
├── CLAUDE.md                       # Master catalog
├── cloned/                         # Cloned repositories
│   ├── repo-a/
│   │   ├── CLAUDE.md              # Auto-generated repo doc
│   │   └── ... (repo files)
│   └── repo-b/
│       └── ...
└── archives/                       # Archived notes (code deleted)
    ├── repo-c.md
    └── repo-d.md
```

## Master Catalog (CLAUDE.md)

The main index at `$SEEKB_PATH/CLAUDE.md`.

### Format

```markdown
# Knowledge Base

Personal GitHub knowledge base managed by SeeKB.

## Repositories

| Repository | Description | Language | Status | Added |
|------------|-------------|----------|--------|-------|
| [owner/repo](https://github.com/owner/repo) | Description | Python | bookmark | 2024-01-15 |
| [owner/repo2](./cloned/repo2/) | Description | TypeScript | cloned | 2024-01-16 |
| [owner/repo3](./archives/repo3.md) | Description | Rust | archived | 2024-01-10 |

## By Status

### Bookmarked (Not Cloned)
- [owner/repo](https://github.com/owner/repo) - Description

### Cloned (Local)
- [repo2](./cloned/repo2/) - Description

### Archived (Notes Only)
- [repo3](./archives/repo3.md) - Description

## By Topic

### Machine Learning
- owner/ml-repo (bookmark)
- local-ml (cloned)

### CLI Tools
- owner/cli-tool (bookmark)

## Statistics

- Total entries: 25
- Bookmarked: 15
- Cloned: 7
- Archived: 3
- Last updated: 2024-01-16
```

### Status Values

| Status | Link Target | Meaning |
|--------|-------------|---------|
| `bookmark` | GitHub URL | Metadata only, no local code |
| `cloned` | `./cloned/repo/` | Full local copy exists |
| `archived` | `./archives/repo.md` | Notes preserved, code deleted |

## Repository CLAUDE.md

Each cloned repo at `$SEEKB_PATH/cloned/<repo>/CLAUDE.md`.

### Format

```markdown
# Repository Name

> One-line description

## Key Info

- **URL**: https://github.com/owner/repo
- **Language**: Python
- **Stars**: 1,234
- **Topics**: ml, ai, nlp
- **Cloned**: 2024-01-15 (shallow)

## Structure

```
src/
├── main.py
├── config.py
└── utils/
```

## Key Files

- `src/main.py` - Entry point
- `README.md` - Documentation

## Commands

```bash
pip install -r requirements.txt
python src/main.py
```

## Notes

Personal learning notes here...

---
*Generated by SeeKB*
```

## Archive Format

Archived notes at `$SEEKB_PATH/archives/<repo>.md`.

### Format

```markdown
# Repository Name (Archived)

> One-line description

## Key Info

- **URL**: https://github.com/owner/repo
- **Language**: Rust
- **Originally Cloned**: 2024-01-10
- **Archived**: 2024-01-20

## What I Learned

- Key insight 1
- Key insight 2
- Useful pattern discovered

## Key Files (Reference)

- `src/lib.rs` - Core implementation
- `examples/basic.rs` - Usage example

## Notes

Personal notes preserved from when code was local...

---
*Archived by SeeKB - Re-clone if needed: `gh repo clone owner/repo`*
```

## Entry Format Quick Reference

### Bookmark Entry (New)

```markdown
| [owner/repo](https://github.com/owner/repo) | Short description | Python | bookmark | 2024-01-15 |
```

### Clone Entry (Upgrade from Bookmark)

```markdown
| [repo](./cloned/repo/) | Short description | Python | cloned | 2024-01-15 |
```

### Archive Entry (Downgrade from Cloned)

```markdown
| [repo](./archives/repo.md) | Short description | Python | archived | 2024-01-15 |
```

## Operations

### Add Bookmark

1. Get repo metadata via `gh repo view`
2. Add row to Repositories table with `status=bookmark`
3. Add to "Bookmarked" section
4. Add to relevant topic sections

### Clone (Bookmark → Cloned)

1. Clone to `$SEEKB_PATH/cloned/<repo>/`
2. Generate repo CLAUDE.md
3. Update table: change link to local path, status to `cloned`
4. Move from "Bookmarked" to "Cloned" section

### Archive (Cloned → Archived)

1. Copy/enhance notes to `$SEEKB_PATH/archives/<repo>.md`
2. Delete `$SEEKB_PATH/cloned/<repo>/`
3. Update table: change link to archive path, status to `archived`
4. Move from "Cloned" to "Archived" section

### Remove Completely

1. Delete from table
2. Remove from all sections
3. Delete archive file if exists
